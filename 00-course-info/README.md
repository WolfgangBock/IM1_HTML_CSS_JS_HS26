# Kursinformationen - Interaktive Medien 1

Willkommen zum technischen Teil des Kurses Interaktive Medien 1!

## Kursübersicht

Dieser Kurs führt dich Schritt für Schritt in die Grundlagen der Webentwicklung ein:
- **HTML** - Struktur von Webseiten
- **CSS** - Gestaltung und Layout
- **JavaScript** - Interaktivität und Verhalten

## Kursdokumente

### Start hier (WICHTIG!)

1. **[Entwicklungsumgebung Setup](./entwicklungsumgebung-setup.md)**
   - VS Code installieren und konfigurieren
   - Browser DevTools kennenlernen
   - Live Server einrichten
   - Test-Projekt durchführen

2. **[Häufige Fehler und Lösungen](./haeufige-fehler-und-loesungen.md)**
   - Typische Anfängerfehler vermeiden
   - Debugging-Strategien
   - Checklisten für Problemlösung
   - **Lesezeichen setzen - du wirst es oft brauchen!**

### Kursinhalte

- `ablauf_interaktive-medien1.md` - Detaillierter Kursablauf mit Lernzielen
- `ablauf_museum.md` - Ablauf des Museum-Projekts
- `techisch_grundlagen.md` - Technische Grundlagen
- `http_protokoll.md` - HTTP-Protokoll Grundlagen

## Kursstruktur

Der Kurs ist in 6 Module aufgeteilt:

1. **01-html-basics** - HTML Grundlagen
2. **02-css-basics** - CSS Grundlagen
3. **03-js-basics** - JavaScript Grundlagen
4. **04-css-layouts** - Fortgeschrittene Layouts (Flexbox & Grid)
5. **05-project-museum** - Finales Praxisprojekt
6. **06-advanced-examples** - Weiterführende Beispiele

## Empfohlene Lernreihenfolge

Arbeite die Module in der angegebenen Reihenfolge durch. Jedes Modul baut auf dem vorherigen auf.
